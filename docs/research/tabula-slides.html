Tabula - Background

Tabula sits between hand-written circuits and generic zkVMs. The motivation starts with the strengths and limits of both.

Option 1

Custom Circuits

Custom circuits can be extremely efficient because the proof system is shaped exactly around the application logic.

  • Strong specialization and tight control over proof cost
  • Application semantics remain explicit inside the circuit
  • But every feature change becomes a proving engineering task
  • Reuse across applications is limited

Option 2

zkVMs

zkVMs provide a much better software stack, but they prove machine execution before application meaning.

  • Reusable toolchains and familiar software workflows
  • No need to build a new circuit for every application
  • Application structure is lowered into ISA-level execution
  • Proof cost pays for machine behavior that many stateful apps do not actually need
