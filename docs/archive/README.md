# Archived Documents

This directory contains historical and superseded documentation.

These files are preserved for design history, migration context, and old
reasoning trails, but they are not the source of truth for the current
workspace.

When an archived document disagrees with the current codebase, prefer these
entry points instead:

- [`../../README.md`](../../README.md)
- [`../design/architecture.md`](../design/architecture.md)
- crate-level `README.md` files under [`../../crates/`](../../crates/)

Archive preserves context, not authority.
